# Retainer

Live-Gantt-Timeline für den Golf-Club-Produktionsplan Oktober 2026.

- `index.html` — eigenständige Seite, einfach im Browser öffnen. Keine Abhängigkeiten, Schriften kommen von Google Fonts.
- Kalender läuft von oben (7. Oktober) nach unten (26. Oktober), fünf Spalten für Michael Bilgeri, Mojo, Lucas Baume, Sam Moodie und Timo.
- Die Zeitlinie und der Fortschrittsbalken in der Datumsleiste laufen sekündlich mit der echten Uhrzeit mit.

Termine und Tasks stehen im `TASKS`- und `BANDS`-Array am Anfang des Skripts.
